# P2 用户体系开发说明

> 项目：医疗安全问答系统
> 阶段：P2（用户体系与会话隔离）
> 完成日期：2026-09-08

## 1. 背景与目标

系统此前为**单用户开放模式**：任何访问者共享同一个会话空间，`chat_history.db` 中的
`conversations / messages` 两表均无用户维度。P2 引入完整用户体系：

- 注册 / 登录 / 登出 / 当前用户查询；
- 密码不落明文，令牌安全签发与吊销；
- 会话按用户隔离：不同账号之间互不可见、不可读写、不可删除；
- 保持既有**游客模式**兼容（未登录仍可试用，行为与旧版一致）；
- 不触碰问答安全护栏（急症拦截、相互作用查询、免责声明三条红线）。

## 2. 总体设计

```
┌─────────────┐   Bearer Token   ┌──────────────────────────┐
│  Gradio UI  │ ───────────────► │  FastAPI (app/api)       │
│ 登录/注册区  │                  │  /api/auth/* 认证路由     │
└─────────────┘                  │  /api/chat 等业务路由     │
                                 │  get_optional_user 依赖   │
                                 └──────────┬───────────────┘
                                            │
                              ┌─────────────▼──────────────┐
                              │ SQLite outputs/chat_history.db │
                              │ users / auth_tokens          │
                              │ conversations(+user_id) / messages │
                              └──────────────────────────────┘
```

核心原则：**新增能力全部可选鉴权**——带有效 token 即按用户隔离，
不带 token 即游客（`user_id = NULL`），向下兼容既有调用与历史数据。

## 3. 数据库变更（同一 chat_history.db 文件）

### 3.1 新增表 `users`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增主键 |
| username | TEXT UNIQUE | 登录名（3-32 位，trim 后唯一） |
| password_hash | TEXT | PBKDF2-HMAC-SHA256，格式 `pbkdf2$sha256$<iter>$<salt>$<hash>` |
| created_at | REAL | 注册时间戳 |
| is_active | INTEGER | 1=正常，0=停用（停用后登录与令牌均失效） |

### 3.2 新增表 `auth_tokens`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| token_hash | TEXT PK | **令牌明文 SHA-256 摘要**（不存明文） |
| user_id | INTEGER | 归属用户 |
| expires_at | REAL | 过期时间（默认 7 天） |
| created_at | REAL | 签发时间 |

### 3.3 变更表 `conversations`

新增列 `user_id TEXT`（可空）：

- `user_id = NULL` ⇒ 游客空间（兼容 P2 之前的全部历史数据与未登录访问）；
- `user_id = '<用户ID>'` ⇒ 登录用户私有会话。

迁移逻辑：`_migrate()` 检测 `PRAGMA table_info(conversations)` 缺少 `user_id` 时
执行 `ALTER TABLE conversations ADD COLUMN user_id TEXT`，**幂等、不丢数据**，
旧行自动归入游客空间。

## 5. API 接口

基础地址：`http://127.0.0.1:8000`，文档：`/docs`。

### 5.1 认证（`/api/auth/*`）

| 方法 | 路径 | 说明 | 请求体 |
| --- | --- | --- | --- |
| POST | `/api/auth/register` | 注册（成功即登录返回 token） | `{username, password}` |
| POST | `/api/auth/login` | 登录 | `{username, password}` |
| POST | `/api/auth/logout` | 登出（吊销当前 token） | - |
| GET | `/api/auth/me` | 当前用户信息 | - |

响应示例（register/login）：

```json
{ "user": { "id": 1, "username": "alice", "created_at": 1788800000.0 },
  "token": "V1Nq..." }
```

后续请求携带：`Authorization: Bearer <token>`。

### 5.2 业务接口（均可选鉴权）

| 方法 | 路径 | 鉴权后行为 |
| --- | --- | --- |
| POST | `/api/chat` | 会话归属校验：非本人会话返回 403 |
| GET | `/api/conversations` | 仅返回本人会话（游客返回 NULL 空间） |
| POST | `/api/conversations` | 新建会话归属当前用户 |
| DELETE | `/api/conversations/{sid}` | 仅归属匹配才删除，否则 404 |
| GET | `/api/history` | 仅能读取本人会话，否则 403 |
| POST | `/api/feedback` | 反馈记录携带 user_id |

无 token 时全部接口行为与 P2 之前完全一致（游客模式）。

## 6. 安全设计

1. **密码保护**：PBKDF2-HMAC-SHA256、随机盐 16 字节、20 万次迭代；
   不存明文、不使用可逆加密。校验用 `hmac.compare_digest` 常量时间比较，防时序侧信道。
2. **令牌保护**：`secrets.token_urlsafe(32)` 签发；数据库只存 SHA-256 摘要，
   即使 DB 泄露也不能直接冒用令牌；默认 7 天过期，登出即时吊销。
3. **防暴力枚举**：注册重名/格式非法返回 400 但不区分原因细节；
   登录失败统一返回 401「用户名或密码错误」，不暴露用户名是否存在。
4. **最小权限**：接口默认匿名可用（游客），只有访问**具体会话**时才做归属校验；
   越权路径统一返回 403/404，不泄露他人会话是否存在。
5. **依赖零新增**：全部使用 Python 标准库（hashlib/secrets/hmac/sqlite3），
   `requirements.txt` 无变化。

## 7. 会话隔离语义

| 访问者 | 能见 | 说明 |
| --- | --- | --- |
| 游客（无 token） | 仅 `user_id IS NULL` 的会话 | 兼容旧数据与未登录试用 |
| 用户 A | 仅 `user_id = A` | 与他人、游客完全隔离 |
| 已登出 / 令牌过期 | 自动回落游客空间 | 令牌失效即隔离 |

## 8. Gradio UI 变更

- 聊天页顶部新增「用户名 / 密码 + 登录 / 注册 / 退出」行，及当前身份提示；
- token 以 `gr.State` 持有，所有 API 请求（问答、会话列表、历史、删除、反馈）
  在登录后自动附加 `Authorization: Bearer <token>`；
- 登录 / 注册 / 退出成功后自动刷新会话列表，切换到当前用户的空间。

## 9. 测试验证

新增 `tests/test_auth.py`（7 项，临时库隔离）：

- 注册成功与重名/非法用户名/短密码拒绝；
- 密码哈希落库且不含明文、格式为 pbkdf2；
- 登录成功/密码错误；停用账号登录与令牌均被拒；
- 令牌签发（库中仅存摘要）、有效校验、登出吊销、登出幂等；
- 会话隔离：A/B 互不可见、归属识别、越权删除被拒；
- 游客空间与用户空间隔离。

回归：`tests/test_chat_history.py`（旧 24 项，含默认游客空间语义）
与 `tests/test_guardrails.py` 全部通过。**合计 31 passed**。

端到端实测（FastAPI TestClient，临时库）：注册→登录→token 鉴权→
A/B 会话互不可见→越权读 403→越权删 404→登出后令牌失效→
chat 接口携带他人 session_id 返回 403，全链路通过。

## 10. 启动与使用

```bash
# 一键启动（FastAPI :8000 + Gradio :7860）
python run.py

# 仅 API
python -m uvicorn app.api.server:app --port 8000

# 仅 Gradio
python app/ui/gradio_app.py
```

使用流程：

1. 打开 `http://127.0.0.1:7860`，点击机器人进入聊天页；
2. 游客可直接提问（会话存于公共空间）；
3. 注册/登录后，会话列表自动切换到本人空间，此后的会话/历史/删除均隔离。

## 11. 与安全红线的关系

P2 只新增**身份与隔离能力**，未改动任何问答逻辑：

- 急症拦截（拨打 120）不变 → 红线「不诊断」保持；
- 相互作用查询与用药问答不变 → 红线「不开处方、不给个性化方案」保持；
- 免责声明照常附注。
